I’ve decided to archive KLIND OS. Why?

I haven’t worked on KLIND OS since 2024. I don’t want to keep working on such horrible code that I wrote more than 4 years ago.

## When I Started Developing KLIND OS

Development of KLIND OS began in 2020, before I even knew what git was. At that time, my web development knowledge was… highly questionable at best.

A lot of KLIND OS is built on the same code I wrote in 2020 during the COVID era, and the entire system architecture is based on it.

I don’t want to work with legacy, poorly written code and keep developing something I can no longer be proud of. I’m not saying KLIND OS is a bad project. Considering I was 11 years old when I was programming it, I think it’s actually a pretty good project.

## What Now

I have other projects besides KLIND OS that I currently enjoy more. Probably no project will ever be as big as KLIND OS, but I’ve realized it’s not about the size of the project — it’s about quality.
